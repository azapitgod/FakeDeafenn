# Sahteleştirilmiş Sağırlaştırma

Bu Discord Eklentisini Kullanarak Sesli Odada İken Sağırlaştırılmış Gözükebilir ve Sesli Odadaki Herkesin Seslerini Duyabilirsiniz.

![Sürüm](https://img.shields.io/badge/version-1.0.0-5865F2?style=for-the-badge)

## Özellikler

| Özellik | Açıklaması |
|---------|-------------|
| **Sahte Sağır** | Sağırlaştırıldığınız Halde Diğer İnsanların Sesini Duyabilirsiniz |
| **İçerik Menüsü** | Sağ Tık İle İsterseniz Sahte Sağırlaştırmayı Kapatabilirsiniz. |
| **Özelleştirilmiş Kısayol Tuşu** | Sahte Sağırlaştırmayı Açıp Kapatmak İçin Tuş Atayabilirsiniz. |
